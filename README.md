# 🤖 RashAI — Your AI Chatbot

RashAI is a personal AI chatbot project built to provide helpful answers, explain programming concepts, and assist with everyday questions.

🌐 **Live Website:** https://rashai.onrender.com

## ✨ Features

- 💬 AI-powered conversations
- 📝 Markdown-formatted answers
- 💻 Programming help for beginners
- 📱 Simple, responsive chat interface
- 🌙 Dark mode
- 💾 Chat history saved in the browser

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- OpenRouter API
- Render for deployment

## 🚀 Project Goals

RashAI is a learning project focused on building and improving a real AI-powered web application while developing skills in web development, backend programming, and API integration.

## 🔐 Security

The OpenRouter API key should be stored as an environment variable on the server:

`OPENROUTER_API_KEY`

Never put API keys or other secrets in frontend code or commit them to GitHub.

## 💻 Run Locally

1. Install Node.js.
2. Clone this repository.
3. Install the project's dependencies.
4. Set `OPENROUTER_API_KEY` in your local environment.
5. Start the server using the command specified in `package.json`.
